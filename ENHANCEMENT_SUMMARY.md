### Game Mechanics

#### Memory Game
- Flip cards to find matches
- Track moves, time, pairs matched
- Performance rating system
- Two difficulty levels

#### Number Guessing
- Think of number 1-100
- User makes guesses
- Progressive hot/cold feedback
- Hint after 10 attempts
- Streak system

#### Math Challenge
- 10 problems × 30 seconds each
- Difficulty: Easy → Medium → Hard
- Speed-based points
- Streak unlocks harder levels
- Real-time score tracking

## 📊 Scoring System

### Games Give Points
- Memory game: Completion bonus
- Number game: Attempt-based bonus
- Math game: Speed & accuracy bonus

### Achievement Multipliers
- Each game: +20-20 score points
- Unlock achievement: +50 to investigation
- Complete all games: +150 total

### Final Score Breakdown
```
Total = Base Score + Game Points + Achievement Bonus
      = Investigation Score + Game Achievements
```
